# Audiobookshelf

## English

Audiobook and podcast server using the official upstream container image. Put media in the project's `audiobooks` and `podcasts` directories; these mounts are read-only to the application. Open `http://<host-ip>:13378`, create users, and back up the config and metadata volumes.

Sources: [Audiobookshelf](https://github.com/advplyr/audiobookshelf), [documentation](https://www.audiobookshelf.org/docs).

## Deutsch

Hörbuch- und Podcastserver mit dem offiziellen Upstream-Container-Image. Medien in die Projektverzeichnisse `audiobooks` und `podcasts` legen; die App erhält darauf nur Lesezugriff. `http://<Host-IP>:13378` öffnen, Benutzer anlegen und Konfigurations- sowie Metadaten-Volumes sichern.

Quellen: [Audiobookshelf](https://github.com/advplyr/audiobookshelf), [Dokumentation](https://www.audiobookshelf.org/docs).
