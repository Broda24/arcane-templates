# Node-RED

## English

Visual flow-based automation. The editor has no authentication configured in this template, so its host port is bound to localhost by default. Keep that binding or put the editor behind an authenticated HTTPS reverse proxy before remote access. Persistent flows and credentials live in `node-red-data`.

Sources: [Node-RED](https://nodered.org/), [official Docker image project](https://github.com/node-red/node-red-docker).

## Deutsch

Visuelle, flow-basierte Automatisierung. In dieser Vorlage ist keine Anmeldung für den Editor eingerichtet; der Host-Port ist daher standardmäßig nur an localhost gebunden. Diese Bindung beibehalten oder vor Fernzugriff einen authentifizierten HTTPS-Reverse-Proxy verwenden. Flows und Zugangsdaten liegen persistent in `node-red-data`.

Quellen: [Node-RED](https://nodered.org/), [offizielles Docker-Image-Projekt](https://github.com/node-red/node-red-docker).
