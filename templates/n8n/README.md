# n8n

## English

Workflow automation using the official image from `docker.n8n.io`. Set a long, unique `N8N_ENCRYPTION_KEY` before deployment; losing it can make stored credentials unrecoverable. The editor is bound to localhost by default. Use an authenticated HTTPS reverse proxy for remote access and back up `n8n-data`.

Sources: [n8n](https://n8n.io/), [official Docker guide](https://docs.n8n.io/hosting/installation/docker/).

## Deutsch

Workflow-Automatisierung mit dem offiziellen Image von `docker.n8n.io`. Vor dem Deploy einen langen, individuellen `N8N_ENCRYPTION_KEY` setzen; bei Verlust können gespeicherte Zugangsdaten unlesbar werden. Der Editor ist standardmäßig nur an localhost gebunden. Für Fernzugriff einen authentifizierten HTTPS-Reverse-Proxy verwenden und `n8n-data` sichern.

Quellen: [n8n](https://n8n.io/), [offizielle Docker-Anleitung](https://docs.n8n.io/hosting/installation/docker/).
