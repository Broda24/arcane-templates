# Gitea

## English

Self-hosted Git service using Gitea's official image from `docker.gitea.com`. Open `http://<host-ip>:3003` and complete the first-run wizard. Git-over-SSH is published on host port 2222; configure that port in clone URLs. Back up `gitea-data` and use HTTPS behind a trusted reverse proxy for remote access.

Sources: [Gitea](https://about.gitea.com/), [official Docker installation guide](https://docs.gitea.com/installation/install-with-docker).

## Deutsch

Eigener Git-Dienst mit dem offiziellen Gitea-Image von `docker.gitea.com`. `http://<Host-IP>:3003` öffnen und den Einrichtungsassistenten abschließen. Git-over-SSH ist auf Host-Port 2222 veröffentlicht; diesen Port in Clone-URLs berücksichtigen. `gitea-data` sichern und für Fernzugriff HTTPS mit einem vertrauenswürdigen Reverse-Proxy verwenden.

Quellen: [Gitea](https://about.gitea.com/), [offizielle Docker-Installationsanleitung](https://docs.gitea.com/installation/install-with-docker).
