# SearXNG

## English

Privacy-respecting metasearch using the official SearXNG image. Set a random `SEARXNG_SECRET` before deployment. The web port is bound to localhost by default; for shared access configure an authenticated HTTPS reverse proxy and update `SEARXNG_BASE_URL`. Do not expose an unprotected public instance.

Sources: [SearXNG](https://github.com/searxng/searxng), [official container documentation](https://docs.searxng.org/admin/installation-docker.html).

## Deutsch

Datenschutzfreundliche Metasuche mit dem offiziellen SearXNG-Image. Vor dem Deploy einen zufälligen `SEARXNG_SECRET` setzen. Der Web-Port ist standardmäßig nur an localhost gebunden; für gemeinsame Nutzung einen authentifizierten HTTPS-Reverse-Proxy konfigurieren und `SEARXNG_BASE_URL` anpassen. Keine ungeschützte öffentliche Instanz betreiben.

Quellen: [SearXNG](https://github.com/searxng/searxng), [offizielle Container-Dokumentation](https://docs.searxng.org/admin/installation-docker.html).
